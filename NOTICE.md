# Attribution and provenance

This repository preserves and adapts Backdrop 1.0.1 by cul8er for MediaPortal 1.39. The import was taken from the verified local ALPHA5 installer, derived from the original `351320_Backdrop_v_1_0_1.mpe1` package and the archived Backdrop editor source.

Selected modern pages and assets were carried over from MediaPortal's DefaultWideHD skin to support current controls. The `MP139` resource directory contains compatibility resources used by this port.

Weather image permission notices are retained at:

- `skin/Backdrop/Media/Weather/128x128/permission.txt`
- `skin/Backdrop/Media/Weather/64x64/permission.txt`

Original authors retain their rights. This import does not apply a new blanket license to upstream code, fonts, or artwork. Existing notices and permissions continue to apply to their respective files.
