# Backdrop ALPHA8 for MediaPortal 1.39

Play now resumes a paused track without triggering the music playlist's selected-item restart. It chooses native action 12 while paused and retains general Play action 68 otherwise. The Moving Pictures thumbnail panel has a horizontal safety margin so its first zoomed cover is fully visible in normal and large thumbnail views.

The 37-case checklist is now **34 passed (91.9%), two partial and one blocked**. Four follow-up cases were assessed; unchanged ALPHA7 results are carried forward rather than claimed as rerun. Right-click context menus work with a visible cursor. The temporary isolated mouse setting was restored.

Remaining limits include immediate topbar focus/click timing, filmstrip edge clipping, unsupported progress dragging, offline TVSeries online rating, TuneIn, populated EPG and full x86 runtime. Only the default theme is shipped. See [validation and evidence](VALIDATION.md).

The AnyCPU editor remains 1.39.0.5. No modified MediaPortal core or plugin binaries, personal settings, caches, databases or test media are included. Close MediaPortal and back up the existing skin before installation.
