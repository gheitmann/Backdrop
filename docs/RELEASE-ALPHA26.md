# Backdrop ALPHA26

Version **1.39.0.26** adds three thematic backgrounds in the cinematic style of
the startup screen. Close MediaPortal and run **Backdrop-Setup-ALPHA26.exe**.
The EXE contains the complete skin package.

## Changelog since ALPHA25

- Added a warmly lit media lounge to Classic Home and Plugins Home.
- Added a studio control console to Settings, related extension screens and
  the Settings category background in BasicHome.
- Replaced the dated Plugins browser art with a cinematic modular AV rack.
- Included the earlier ALPHA25 artwork follow-up: 51 original Backdrop control
  textures restored, including MENU/Live TV tabs, list/playlist states, TV
  guide surfaces and the artist/album dialog frame.
- Kept the existing cinematic BasicHome/startup scenes, horizontal main menu,
  Latest Recordings caption fix and vertical recording-menu headings.
- Rebuilt the standalone menu editor and single-file setup as 1.39.0.26.

## Validation and limits

The source package contains 2,408 payload files and 558 skin XML definitions.
Six static validation commands passed (6/6 of the selected command set).
The three new images were checked in every intended XML location and included in
both native package indexes. See [ALPHA26 build report](ALPHA26-BUILD-REPORT.md)
for final package and installer verification results.

Live visual confirmation of the new backgrounds, recording pagination flash
and full x86 runtime coverage remain open. The previous Defender report has
not been resolved; this release makes no security or broad compatibility claim.
Personal demo data and the separate local MediaPortal audio correction are not
included.
