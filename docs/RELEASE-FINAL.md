# Backdrop 1.39.0.33

## Changes since BETA5

- Restore Backdrop Settings colours and remove the top overlay.
- Update TV backgrounds, Latest Pictures spacing and subtitle provider alignment.
- Incorporate tester-supplied TV and radio guide overlays and video facade changes.
- Adjust mini guide and TV recording dialogs.

Download the single Backdrop-Setup-1.39.0.33.exe and close MediaPortal before installation.

The TV guide and package have been checked locally. The active-recording dialog, recording indicator and mini-guide changes still need user testing with a real TV source. Full x86 runtime coverage remains pending. No third-party plugin installers or MediaPortal core changes are included.
